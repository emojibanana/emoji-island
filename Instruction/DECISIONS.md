# Architecture & Technical Decisions

| ID | Decision | Rationale | Status |
|---|---|---|---|
| D-001 | Product name `Emoji Island`; repo `emoji-island`. Public copy MUST NOT use "Dynamic Island" or "JARVIS". IPC channels use `domain:action`. | Avoids trademark issues; consistent naming. | Locked |
| D-002 | Stack: Electron, React, TypeScript (strict), Tailwind CSS, built with `electron-vite` React-TS template. Package manager `npm`. Exact versions are resolved and locked in T-001 [VERIFY: latest stable]. | Boring, well-documented stack that free models write reliably. | Locked |
| D-003 | Dependency Allowlist. Prod: `react`, `react-dom`, `electron-store`, `electron-log`, `zod`, `lucide-react`, `clsx`, `tailwind-merge`. Dev: `electron`, `electron-vite`, `electron-builder`, `typescript`, `tailwindcss`, `postcss`, `autoprefixer`, `eslint`, `prettier`, `vitest`, `@vitest/coverage-v8`, `@testing-library/react`, `@testing-library/jest-dom`, `jsdom`, `@types/*` for listed packages. All MIT/Apache/ISC. No other package may be installed. | Prevents agent from adding arbitrary packages. | Locked |
| D-004 | No animation library. Animations use CSS transitions only. | Reduces dependencies and bundle size. | Locked |
| D-005 | Storage: non-secrets in `electron-store` (schema versioned). Shelf files in `userData/shelf`. Limits: 50 items, 500 MB total, 100 MB per file, image preview <= 2 MB. Chat history 50 messages, AI context 8 messages. No binaries or base64 above 64 KB in electron-store. | Data is tens of items; JSON store is enough. | Locked |
| D-006 | AI: MockProvider is mandatory and default. Exactly one real adapter (OpenAI-compatible chat completions). `aiEndpoint` and `aiModel` default to `null`. Key stored in main process only via `safeStorage`; if `isEncryptionAvailable()` is false, keep in memory for the session and show "key not persisted". Renderer never receives the key. Output is untrusted plain text. No voice, tools, shell, file access, or system control. Gemini adapter is Future. *(Implemented in v0.2; v0.1 contains MockProvider only).* | Safe default; 9router already routes to other models. | Locked |
| D-007 | AI endpoint rule: `https` required, except loopback hosts (`localhost`, `127.0.0.1`, `::1`) where `http` is allowed in all builds. HTTP client: `redirect: 'error'`, 15 s AbortController timeout, max response body 1 MB, content-type `application/json`, require `choices[0].message.content` as non-empty string <= 4000 chars, 4xx -> `PROVIDER_ERROR` without retry, network error -> max 1 retry, never forward Authorization to another host. *(Implemented in v0.2; v0.1 contains MockProvider only).* | Prevents SSRF, oversized responses, key leakage. | Locked |
| D-008 | SMTC spike: 8 h total including review. Evaluate ONE primary option first. Checkpoint at 4 h: if no media session can be read, switch to ONE fallback. At 8 h without PASS: Degraded, stop implementation. Extension needs human approval. Task "Record spike result" sets this row to Locked (PASS) or Degraded. No media UI beyond a placeholder before that. Media tasks exist as `-L` (full control) and `-D` (read-only/unavailable) variants. Polling every 3 s only while a media session exists. | SMTC is the highest technical risk; failure must not block the demo. | Proposed |
| D-009 | Overlay: one frameless, transparent, always-on-top `BrowserWindow` on the primary display, top-center, `skipTaskbar: true`, `resizable: false`, `hasShadow: false`; `setAlwaysOnTop(true, 'screen-saver')`. Expand/collapse by resizing the same window. Exclusive-fullscreen apps may still cover it (documented limitation). No full-screen click-through overlay. | Small window avoids click-through complexity. | Locked |
| D-010 | Focus model: collapsed = non-focusable; expanded = focusable; blur collapses after 300 ms unless the renderer reports input active via `window:setInputActive {active:boolean}`. "Glass" = semi-opaque rgba background + 1 px border; no dependency on desktop blur. | Main process cannot see input state; blur must not interrupt typing. | Locked |
| D-011 | Single instance via `app.requestSingleInstanceLock()` (second launch shows the island). Global hotkey default `Ctrl+Alt+Space`, configurable in Settings; if registration fails, show a notice and fall back to tray toggle without crashing. Tray: show/hide/quit. Launch at login is Future. | Prevents duplicate overlays; hotkeys can conflict. | Locked |
| D-012 | File drop: preload exposes a helper via `contextBridge` calling `webUtils.getPathForFile(file)`. Renderer sends only that path through `shelf:addFromDrop`. T-005 verifies it works under `contextIsolation: true` + `sandbox: true` and records the result here. Main treats the path as untrusted: `lstat` + `realpath`, reject symlinks/junctions/devices/directories, check free space and caps, stream-copy to temp file in `userData/shelf`, atomic rename, never execute. Filename sanitizer rejects/rewrites reserved names (CON, PRN, AUX, NUL, COM1-9, LPT1-9), illegal chars `< > : " / \ | ? *`, trailing dots/spaces, duplicates (append counter), total path > 240. | `File.path` was removed; paths must be validated. | Locked |
| D-013 | Image preview: `shelf:getPreview` returns a data URL for PNG, JPEG, WebP, GIF <= 2 MB only. SVG, HTML, XML, executables rejected. Production CSP: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'none'; object-src 'none'; base-uri 'none'; form-action 'none'`. All HTTP runs in the main process. | Safe local preview without relaxing CSP. | Locked |
| D-014 | Preload exposes a frozen typed `islandApi` with one method per allowed channel. It MUST NOT expose `ipcRenderer`, `require`, `process`, or generic `send`/`invoke`. All IPC payloads are validated in main with `zod`. | Minimizes attack surface. | Locked |
| D-015 | IPC envelope: `{ ok: boolean, data: T | null, error: { code, message } | null }`. Codes: VALIDATION_ERROR, STORAGE_ERROR, NETWORK_ERROR, TIMEOUT, PROVIDER_ERROR, MEDIA_UNAVAILABLE, FILE_TOO_LARGE, UNSUPPORTED_TYPE, PATH_INVALID, PERMISSION_DENIED, UNKNOWN_ERROR. Shared types live in `src/shared/types.ts`. Timestamps are epoch milliseconds everywhere. | Single contract for all tasks. | Locked |
| D-016 | Weather: Open-Meteo, no key. Default location Jakarta (-6.2, 106.8), or manual coordinates. 30-minute cache; shown as "stale" up to 24 h, then "offline". Timeout 3 s, 1 retry, 1 s backoff. Metric units. | Free and keyless. | Locked |
| D-017 | UI sizes (CSS px at 100%): collapsed 280x40, expanded 420x360, max height 420, 12 px top margin. Rely on Chromium DIP scaling for 125%/150%. | Fixed sizes remove agent guesswork. | Locked |
| D-018 | Naming: kebab-case for non-component files, PascalCase for React components and types, camelCase for functions/variables. Layout follows the `electron-vite` template (`src/main`, `src/preload`, `src/renderer`) plus `src/shared`. Env vars (no values committed, `.env.example` required): `EMOJI_ISLAND_LOG_LEVEL`. | Predictable paths. | Locked |
| D-019 | Release: GitHub Actions (test/lint/build on pull request; release on `v*` tag). Artifacts: `EmojiIsland-${version}-setup.exe` (NSIS) and `EmojiIsland-${version}-win-x64-portable.zip`. MIT License. Unsigned builds; README states SmartScreen warning. | Free CI for public repos. | Locked |
| D-020 | Testing: Vitest, @testing-library/react, jest-dom, jsdom. >= 70% line coverage on pure-logic modules only. UI rendering, window management, SMTC bridge, drag/drop glue, tray, packaging excluded. GUI behavior verified by `manual_check_id` in `TESTING.md`. | Native features are hard to automate. | Locked |
| D-021 | Effort: `review_hours = ceil(agent_hours * 0.2)`; `estimated = agent + review`; `buffered = sum * 1.15`. v0.1 official target = 7-8 weeks at 14 h/week (<= 112 h buffered). Minimum Demo Scope excludes E2E, landing page, true drag-out, AI streaming, v0.2 tasks, and T-007b. (Note: 56 h was a stretch target and is retired). | Clarifies boundary of Minimum Demo and provides a realistic timeline. | Locked |
| D-022 | Cut priority (first to cut within v0.1): landing page, E2E tests, true drag-out, AI streaming, weather city search, advanced thumbnails, full media control. NOT cuttable: single instance lock, hotkey, overlay shell, clock, basic weather, shelf (copy/list/reveal/copy path/delete), MockProvider chat, basic packaging, README, LICENSE. | Protects the demo. | Locked |
| D-023 | MVP Scope: v0.1 in = clock/weather, media (Locked or Degraded variant), shelf, AI chat (MockProvider only), tray, hotkey, single instance, settings core (location, hotkey, reducedMotion). v0.2 = real OpenAI-compatible adapter + AI settings. Future = Gemini adapter, voice, true drag-out, multi-monitor, fullscreen auto-hide, launch at login, macOS/Linux. | Thin vertical slice boundaries. | Locked |
| D-024 | Version Scope: v0.1 ships MockProvider only plus Settings core (location, hotkey, reducedMotion). The real OpenAI-compatible adapter (T-027, T-028, T-030) is v0.2 and is NOT part of the v0.1 buffered total. Official calendar target: 7-8 weeks at 14 h/week. | Ensures v0.1 delivers the fastest viable Hero Moment. | Locked |
